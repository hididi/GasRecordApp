# 使用说明（给家里人看的版本）

## 一、第一次用（3 分钟）

1. 打开 App，点首页的「**拍照抄表**」，把镜头对准燃气表的读数窗，尽量让表盘占满取景框、避免反光，按快门。
2. 拍完会自动识别表数。**识别的结果一定要核对**：看红格子里的数字对不对。
   - 识别错了就点「放大看表盘」，照着表盘用下面的数字键盘逐位敲：黑格敲整数（5 位），红格敲小数（3 位）。
   - 也可以点「识别候选」里的某一条，再按 ⌫ 改最后一位。
3. 确认拍摄时间、地点、当日气温都对（气温会自动查当地历史天气），点「**确认入库**」。
4. 打开「**设置**」→ 家庭位置：填一次「城市+区」并查找，或者用当前定位。这样照片没带 GPS 时也能查气温。
5. 打开「**费用**」→ 阶梯气价：把当地燃气公司公示的三档单价和年度上限改成你家的真实数字，点保存。

## 二、每天怎么用

- 每天不定时拍 0～n 张都行，重要的是**尽量每天固定时间拍 1 张**，这样推算最准。
- 同一天拍两张以上的话，两张的差值就是当天精确用量（比均摊估算准）。
- 从相册导入老照片也可以；照片里的拍摄时间和位置会被读取，气温按照片日期查。
- 忘记拍照的日子不影响记账，只是那几天会按间隔天数均摊（App 里标「估」）。

## 三、交费后要做的

1. 「费用」→ 交费记录 → 「添加」：
   - 交费时的表读数（照片里那个数）
   - 交费金额（可不填）
   - 当前档位（第几档）
   - 本档剩余气量（燃气公司 App 或账单上一般有）
2. 保存后，App 会从这条记录出发，用之后的真实表读数推出现在还剩多少低价气，并按阶梯价算出这段时间的费用。

## 四、看数据

- **首页**：今天用了多少、本月用了多少、本月预计花多少钱、本档还剩多少气。
- **统计**：选区间看用气量、温度、逐日明细，可以导出 CSV 发给家人或者存到电脑。
- **费用**：改阶梯价、看交费记录、算任意区间的费用。

## 五、备份与隐私

- 照片、读数全部存在手机本地，不会上传到任何服务器。
- 联网只做两件事：查拍摄地点当天的气温（Open-Meteo）、把经纬度换成地名。
- 换手机前请在「设置」→ 数据 → 「导出完整备份 JSON」，新手机上用「从备份文件导入」。
- 卸载 App 会删除数据，记得先导出。

## 六、常见问题

**识别不准怎么办？**
点「放大看表盘」双指放大，照着表盘用数字键盘逐位输入即可。识别只是帮你少打几个字。

**滚轮正在转、两个数字叠在一起？**
取靠前一点的那个数字，登记后下一次读数会自然对齐；App 只关心差值，差一位会让当天用量偏差，建议核对。

**温度显示「无位置」？**
照片没有 GPS 且没设家庭位置。去设置里填一次家庭位置，或在确认页手动填当日气温。

**数字看起来不对（比上次小很多）？**
通常是录错或者换了表。App 会提示「读数小于上一条记录」，确认换表就继续保存。
